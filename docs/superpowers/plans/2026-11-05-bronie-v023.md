# v0.23 – bronie: typy ciosu, dwa tryby, rzadkość, pas budowlańca – plan wdrożenia

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Broń zmienia sposób walki: typ ciosu × materiał problemu, dwa tryby (B z odnowieniem), rzadkość widoczna w ręce postaci, druga broń z rzadkim pasem; 22 obecne + 17 nowych broni; najpierw Godot, potem port na GBA.

**Architecture:** Wszystkie liczby w `GBA/data/game.json` (nowa sekcja `hitTypes`, `weaponRarities`, rozszerzone `weapons[]` o `hit`, `modeA`, `modeB`, nowe stany). Rdzeń C# (`GODOT/src/LifeLike.Core`) dostaje: mnożnik ciosu (`HitCalc`), wzory pól (`HitPattern`), wieloceowy atak trybu A/B, odnowienie trybu B, rzadkość i drugą broń w stanie budowy, szerszą maskę broni w profilu. Potem bot (dla balansu), UI i grafika Godota, na końcu port 1:1 na GBA (`core.h`/`meta.h`, `gen_data.py`) z testem złotym.

**Tech Stack:** C# net10.0 + xUnit, Godot 4.7.2 .NET, C++20/Butano (GBA), Python (gen_data.py, eksporter grafik).

**Spec:** `docs/superpowers/specs/2026-11-05-bronie-v023-design.md` (zatwierdzony 2026-11-05). Propozycje liczb i trybów: `docs/v0.23/katalog_broni.pdf` (źródło: `docs/v0.23/make_katalog_broni.py` – tablice `OLD`, `NEW`, `EFF`, `PAT`).
